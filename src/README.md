# Program source

- `backend_v2/`: market and weather inputs, solar and demand modelling,
  rolling-horizon optimisation, and simulation control.
- `database_v2/`: SQLite schema, data access, typed models, and bundled defaults.
- `frontend_v2/`: the PyQt6 desktop application and replay views.
- `team_21_the_grid_optimists/`: the existing `gridsync` command-line entry point.

See the root [README](../README.md) for setup and the
[backend guide](backend_v2/README.md) for simulation commands.
